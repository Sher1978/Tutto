### (Home screen — "Live Reverse Auctions", mobile, dark theme)

## 0. Роль и задача агента

Ты — senior frontend engineer, специализирующийся на pixel-perfect UI. Собери экран **Home / Live Reverse Auctions** приложения Tutto Minutto строго по спецификации ниже. Не меняй пропорции, отступы, радиусы и иерархию текста по своему усмотрению — если данных не хватает, бери ближайшее значение из шкалы Tailwind (4/8px grid), а не произвольное.

## 1. Общая эстетика (art direction)

**Стиль:** "Neon Tropical Luxury" — ночной тропический курорт + неоновая киберпанк-подсветка + премиальный travel-маркетплейс (аналог Booking.com × Vegas neon signage).

- Тёмный фон, вся типографика и акценты светятся на контрасте.
- Никаких experimental/tech-шрифтов (Orbitron и т.п.) — только чистые гротески.
- Карточки — стекло/глассморфизм на тёмном, с мягким неоновым свечением по краю, а не жёсткой обводкой.

## 3. Типографика

- Основной шрифт интерфейса: **Inter** (тексты, лейблы, кнопки).
- Моноширинный для чисел/таймеров: **JetBrains Mono** (счётчики "00:04:18", возможно суммы ставок).
- Логотип "TUTTO MINUTTO": жирный geometric sans (**Outfit**, вес 700–800), uppercase, letter-spacing +1–2%, заливка — линейный градиент cyan→green, слева направо, с лёгким text-shadow/glow того же цвета (blur ~12–16px, opacity 40%).
- Тэглайн "Here, you choose!": Inter Regular/Medium, `#E7ECF3`, ~16–18px.

Иерархия размеров (примерно, mobile 390px width base):
- Logo: 32–34px / line-height tight
- Tagline: 16px
- Section heading ("ASIAN HUBS", "LIVE REVERSE AUCTIONS"): 15–16px, Inter SemiBold, uppercase, letter-spacing +4–6%, `#F5F7FA`
- Hub tabs: 15px, SemiBold, uppercase
- Category icon label: 11–12px, Bold, uppercase, `#F5F7FA`
- Auction card title: 17–18px, SemiBold, `#F5F7FA`
- Auction card subtitle: 13px, Regular, `#9AA5B8`
- Bid labels: 12–13px Regular `#9AA5B8`; значения 15–16px SemiBold `#F5F7FA`
- Countdown timer: 22–24px, JetBrains Mono Bold, neon green `#3DFFB0`, glow
- CTA button text: 14px, Bold, uppercase, letter-spacing +2%

## 4. Структура экрана (сверху вниз, mobile, safe-area aware)

### 4.1 Status bar (системный, не рисовать вручную — использовать нативный/симулированный)
Время, сигнал, wifi, батарея — стандартный iOS-стиль, светлый на тёмном фоне.

### 4.2 Header
- Слева: иконка "paper-plane / send" (outline, белая, 22px) — вероятно deep-link на inbox/telegram-интеграцию.
- Центр: логотип "TUTTO MINUTTO" (см. типографику), под ним тэглайн "Here, you choose!" по центру.
- Справа: иконка "•••" (more, кружок с тремя точками) 22px белая.
- Отступы: padding 20px по горизонтали, ~16px сверху от safe-area.

### 4.3 AI Agent Card
Карточка на всю ширину (минус 20px паддинги), `border-radius: 16px`, стекло-фон.
Layout: flex row, space-between.

**Слева:**
- Круглый аватар 44–48px, реальное фото человека, с зелёной точкой online-статуса (8px, `#3DFFB0`, обводка фона) в правом нижнем углу аватара.
- Имя: "Kaitlyn L. | @kaitlyn.l" — Inter SemiBold 14–15px белый.
- Строка ниже: ★ (gold) "4.9" + " • " + "Online" (зелёный текст) — 12–13px.

**Справа:** отдельный вложенный pill-бейдж, фон `rgba(61,255,176,0.12)`, обводка `1px solid rgba(61,255,176,0.4)`:
- Точка + "AI SALES AGENT" — 11px Bold uppercase, зелёный.
- "ACTIVE • Online" — 11px, зелёный/белый.
- "Response Time: <1m" — 10–11px, `#9AA5B8`.

### 4.4 Section: "ASIAN HUBS" + Hub Tabs
- Заголовок секции (см. типографику), margin-top 24px от карточки агента.
- Горизонтальный скролл табов (scrollable row), gap 20–24px:
  `🌴 BALI` (активный) | `PHUKET` | `BANGKOK` | `SEOUL` | `TOKYO`
- Активный таб: цвет `#22E4FF`, под ним underline 2px `#22E4FF` шириной под текст (не на всю ячейку), с лёгким свечением.
- Неактивные табы: `#9AA5B8`, без underline.
- Только у активного пункта (Bali) — эмодзи пальмы перед текстом.

### 4.5 Категории (иконки-кнопки)
Горизонтальный ряд (scrollable при нехватке места), 5 элементов: **RESORTS, TOURS, EXPERIENCES, YACHTS, STAYS** (STAYS обрезан на скрине — значит либо скролл, либо ужать gap).

Каждый элемент:
- Квадрат-сквиркл (`border-radius: 20px`), размер ~72×72px, градиентная заливка по категории (см. таблицу цветов), белая line-icon по центру (24–26px): пляжный зонт / самолёт / бокалы шампанского / яхта / машина.
- Лёгкая внутренняя тень/glow снизу иконки под цвет градиента.
- Подпись под иконкой по центру, отступ 8px, uppercase bold белый.
- Gap между элементами ~14–16px.

### 4.6 Section: "LIVE REVERSE AUCTIONS"
Заголовок как в 4.4, margin-top 28px.

**Карточки-аукционы** — горизонтальная карусель (snap-scroll), карточка ~78–82% ширины экрана, gap 12px между карточками, чтобы следующая немного "выглядывала" справа.

Каждая карточка (`border-radius: 18–20px`, glass-фон):
- Верх: фото объекта (интерьер/бассейн), `border-radius: 14px`, соотношение ~4:3, занимает верхние ~45% карточки, либо для широкой карточки — фото слева (40%) + инфо справа (60%), как на карточке #1 скрина (тут фото слева квадратом, а не сверху — уточни у агента какой вариант ты используешь, в примере фото слева).
- Заголовок: `"{ГОРОД}: {Название отеля} - {Тип комнаты}"` — bold белый, может переноситься на 2 строки.
- Подзаголовок: `"{★★★★★} {Тип}, {Локация}"` — серый.
- Блок цифр (2 строки, label слева серый / value справа белый, выравнивание space-between):
  - "Current Low Bid:" — `$345`
  - "Original Price:" — `$980` (можно strikethrough, показать что это была стартовая цена)
- "12 Bidders" — отдельной строкой, серый/белый, 13px.
- Таймер обратного отсчёта — крупный, моно-шрифт, зелёный неон, формат `HH:MM:SS`, слева направо ("00:04:18").
- CTA-кнопка на всю ширину карточки снизу: pill, cyan-градиент, "VIEW OFFER / BID NOW", uppercase bold.

*(Вторая, частично обрезанная карточка "Kata Rocks Villa" — тот же паттерн, но фото сверху на всю ширину, заголовок "Phuket: Kata Rocks Villa", "TIMER 00:09:55", "Current Bid: $410" — то есть возможны 2 layout-варианта карточки: с "Original Price + Bidders" и упрощённый без них. Если это единый компонент — сделай Bidders/Original Price опциональными пропсами.)*

### 4.7 Bottom Navigation Bar
Фиксированная нижняя панель, тёмный фон (чуть темнее основного, `rgba(10,14,20,0.9)` + blur), высота ~64px + safe-area, top border `1px solid rgba(255,255,255,0.06)`.

5 пунктов, равномерно распределены, каждый: line-icon 22–24px + подпись 10px под ним:
1. **HOME** (иконка дом, заполненная/активная — белая/cyan)
2. **MY BIDS** (звезда, outline)
3. **EXPLORE** (лупа, outline)
4. **CHAT** (речевой пузырь, outline)
5. **ACCOUNT** (силуэт человека, outline)

Активный пункт (Home) — иконка и текст в акцентном цвете (белый/cyan, чуть ярче остальных), неактивные — приглушённый серый `#7C889C`.

## 5. Отступы и сетка (базовая единица 4px)

- Горизонтальный контентный padding: **20px** по всему экрану.
- Вертикальные gap между секциями: **24–28px**.
- Радиусы: крупные карточки 16–20px, иконки-категории 20px, кнопки — pill (999px), мелкие бейджи 10–12px.
- Все интерактивные элементы ≥ 44px тач-таргет.

---

## 6. Состояния и поведение

- Hub tabs, category icons, auction cards — горизонтальный scroll с momentum, без видимого scrollbar.
- Countdown timer — живой, обновляется каждую секунду; при <1 минуте можно менять цвет на предупреждающий (например красный/оранжевый) — если не указано иное, оставить зелёным всегда.
- Bottom nav — sticky/fixed, не скроллится с контентом.
- Background-изображение — фиксированное (не двигается при скролле контента), контент скроллится поверх него.

## 7. Технические указания для агента

1. Собирай как переиспользуемые компоненты: `Header`, `AgentCard`, `HubTabs`, `CategoryGrid`, `AuctionCard`, `BottomNav`.
2. Фиксируй высоту карточек через контейнер, а не через контент (`h-[Npx]` только как fallback, предпочтительно `min-h` + flex, чтобы контент не расползался) — судя по истории чата, именно смещение элементов было проблемой; используй `flex` + `items-center`/`justify-between` вместо абсолютного позиционирования там, где это возможно.
3. Все цвета — переменные (CSS vars / Tailwind theme tokens), не хардкодить хексы по месту.
4. Иконки — line-icon набор (например Lucide/Feather), одна толщина линии на весь экран (не смешивать filled/outline произвольно).
5.Шрифты подключать реальные (Inter, Outfit, JetBrains Mono) через локальные файлы или Google Fonts, не системный fallback.
6. Тестировать на ширине 390px (iPhone 14/15 base) — это референсный экран.
