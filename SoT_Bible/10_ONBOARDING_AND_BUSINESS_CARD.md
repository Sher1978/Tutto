## 1. Онбординг Клиента

### 1.1 Концепция

Клиентский онбординг — максимально короткий (≤ 30 секунд). Цель: понять роль, хаб и язык пользователя, зарегистрировать его через Telegram initData, и сразу направить в ленту.

## 2. Онбординг Партнёра (Исполнителя / Бизнеса)

### 2.1 Концепция

Партнёрский онбординг — **AI-диалог** (чат-бот стиль внутри TMA). ИИ задаёт 6–8 вопросов о бизнесе, пользователь отвечает в свободной форме. На основе ответов:
1. Заполняется `business_profiles` (company_name, category, knowledge_base_text)
2. Генерируется **бизнес-карточка** (публичный профиль исполнителя)
3. Создаётся первичная база знаний для AI Sales Agent

Этот флоу запускается когда пользователь выбрал роль «Предлагаю услуги» (provider или both) **ИЛИ** вручную через `/b2b/onboarding`.

### 2.2 Флоу AI-опроса

```
[Trigger: роль = provider / both]
       │
       ▼
[Экран: «Расскажи о своём бизнесе»]
  Заголовок: «🤖 AI-помощник настроит ваш профиль»
  Подзаголовок: «Ответьте на несколько вопросов — займёт 2–3 минуты»
  [ Начать → ]
       │
       ▼
[Чат-интерфейс: AI задаёт вопросы по одному]

  Q1 → Q2 → Q3 → Q4 → Q5 → Q6 → [Опциональные Q7, Q8]
       │
       ▼
[Генерация профиля через LLM]
       │
       ▼

  [ ✅ Подтвердить ] [ ✏️ Редактировать ]
       │
       ▼

```

BUSINESS_PROFILE_GENERATOR_PROMPT = """

Название: {company_name}
Ниша: {category}
Прайс-лист и услуги: {services_text}
Район и зона покрытия: {location_text}
Преимущества и факты: {advantages_text}
Ссылки: {links}
Рабочее время: {working_hours}
Дополнительные условия: {extra_conditions}
---

ЗАДАЧА:
Сгенерируй JSON со следующими полями:

{
  "company_name": "Официальное/красивое название",
  "tagline": "Короткий слоган (до 60 символов, продающий)",
  "category_slug": "slug из рубрикатора (transport_motorbike, cleaning_regular и т.д.)",
  "knowledge_base_text": "Структурированный текст для AI Sales Agent (см. формат ниже)",
  "card_description": "Публичное описание для бизнес-карточки (до 200 символов)",
  "services_list": [
    {"name": "Название услуги", "price": "цена", "unit": "день/час/шт", "note": "доп.инфо"}
  ],
  "coverage_area": "Район/зона работы",
  "advantages": ["Преимущество 1", "Преимущество 2", "Преимущество 3"],
  "working_hours": "Время работы",
  "social_links": ["https://..."],
  "ai_min_budget": 0.00
}

ФОРМАТ knowledge_base_text (для AI Sales Agent):
Структурированный текст с прайс-листом, условиями, зоной доставки и спец.условиями.
Пример:
"Прокат Honda PCX 150: $11/день (мин. 3 дня). Yamaha NMAX: $13/день.

ПРАВИЛА:
1. Tagline пиши на языке ниши пользователя (русский если ответы на русском).
2. ai_min_budget вычисли как минимальную цену из прайса (или 0 если не указана).
3. card_description — продающий, без воды.
4. knowledge_base_text — структурированный, конкретный, без лирики.
5. Верни ТОЛЬКО валидный JSON, без markdown-обёртки.

### 2.5 FastAPI Endpoint — Генерация профиля

```python
# ai_worker/services/profile_generator.py

import json
from openai import AsyncOpenAI
from core.config import settings

client = AsyncOpenAI(api_key=settings.OPENAI_API_KEY)


async def generate_business_profile(answers: dict) -> dict:
    """
    Принимает ответы пользователя на AI-вопросы,
    возвращает структурированный бизнес-профиль.
    """
    prompt = BUSINESS_PROFILE_GENERATOR_PROMPT.format(
        company_name=answers.get("company_name", ""),
        category=answers.get("category", ""),
        services_text=answers.get("services_text", ""),
        location_text=answers.get("location_text", ""),
        advantages_text=answers.get("advantages_text", ""),
        links=answers.get("links", "нет"),
        working_hours=answers.get("working_hours", "не указано"),
        extra_conditions=answers.get("extra_conditions", ""),
    )

    response = await client.chat.completions.create(
        model="gpt-4o-mini",
        response_format={"type": "json_object"},
        messages=[{"role": "user", "content": prompt}],
        temperature=0.4,
        max_tokens=1024,
    )

    return json.loads(response.choices[0].message.content)


# FastAPI endpoint (в main.py)
# POST /api/v1/onboarding/generate-profile
# Body: { "answers": {...} }
# Response: { "profile": {...} }
```

### 3.2 Поля бизнес-карточки (Data Model)

```typescript
interface BusinessCard {
  // Идентификация
  id: string;
  company_name: string;
  tagline: string;              // «Лучшие байки Пхукета с доставкой»
  
  // Медиа
  logo_url?: string;
  cover_photo_url?: string;
  
  // Категория
  category_l1_slug: string;
  category_l2_slug?: string;
  
  // Контент
  card_description: string;    // До 200 символов
  services_list: ServiceItem[];
  advantages: string[];        // До 5 пунктов
  
  // Локация
  hub: string;
  coverage_area: string;
  
  // Время
  working_hours: string;
  
  // Контакты
  social_links: string[];
  
  // Статистика
  rating: number;
  deals_count: number;
  
  // Тарифы и AI
  sub_plan: 'free' | 'pro_manual' | 'ai_business';
  ai_enabled: boolean;
}

interface ServiceItem {
  name: string;
  price: number;
  unit: string;     // 'день' | 'час' | 'шт' | 'услуга' | 'кг' | 'персона'
  note?: string;    // Дополнительное условие
}
```
