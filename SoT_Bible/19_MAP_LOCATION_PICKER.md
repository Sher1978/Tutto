# 19. Интерактивная карта для выбора ГЕО (Map Location Picker)

## Суть
Вместо того, чтобы вручную вбивать локацию, пользователи могут визуально выбрать нужную точку прямо на интерактивной карте. Это повышает удобство использования и точность позиционирования, что критично для нашей "Матрицы выдачи".

## Реализация
Мы используем открытое бесплатное решение: **Leaflet** + **React-Leaflet** на базе **OpenStreetMap**. 
- Не требует API ключей Google и привязки карт.
- Полностью бесплатно.

### Компонент `MapLocationPickerModal`
- Попап открывается по нажатию на кнопку `🗺 Карта` в карточках создания заявки.
- Содержит интерактивную карту с возможностью зума и перетаскивания.
- Маркер фиксируется в центре экрана. Пользователь двигает карту под маркером.
- По нажатию кнопки подтверждения, координаты передаются обратно в функцию `detectUserLocation` (или схожую логику из `geo.ts`), которая с помощью формулы Haversine вычисляет ближайший Хаб (L1) и Район (L2). 
- Это гарантирует целостность базы данных (L1 всегда будет системным), но при этом дает клиенту свободу выбора на карте.
