## 1. Назначение системы

**NeedTnow** — платформа локального обратного аукциона (Reverse Auction) для курортных хабов ЮВА (Пхукет, Бали, Бангкок, Вьетнам/Нячанг).

### Ключевая идея

| Роль | Действие |
|---|---|
| **Клиент** | Создаёт запрос со своей ценой или «Жду предложений» |
| **Исполнитель / Бизнес** | Делает встречные офферы: вручную или через **AI Sales Agent** (3–5 секунд) |
| **Сделка** | Закрывается в Telegram-чате или внутри TMA |

> **Ключевое отличие от конкурентов:** не клиент ищет исполнителя — исполнители конкурируют за клиента в режиме реального времени.

## 3. Технологический стек

| Слой | Технологии | Назначение |
|---|---|---|
| **Frontend** | React 18, Vite, TypeScript, Tailwind CSS, `@twa-dev/sdk`, Lucide Icons, Framer Motion | TMA интерфейс, анимации, нативная интеграция с Telegram |
| **Backend Core** | Supabase (PostgreSQL, Supabase Auth, Edge Functions, Realtime Engine) | БД, авторизация по `initData`, подписки на события |
| **AI Engine** | Python 3.11, FastAPI, LangChain / OpenAI API, `pgvector` | Автономный ИИ-менеджер, генерация откликов, RAG |
| **Notification Engine** | Node.js (GrammyJS / Telegraf) | PUSH-уведомления, Deep Links, сервисные сообщения |
| **Payments** | Telegram Stars, TON Connect, CryptoPay API, Local QR (PromptPay / VietQR) | Приём оплаты за подписки PRO / AI |
| **Partner Engine** | Supabase Functions + Referral Tracking Table | Партнёрская программа: реферальные ссылки, 20% комиссия |
