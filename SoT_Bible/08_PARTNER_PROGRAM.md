# 📁 08_PARTNER_PROGRAM.md
> **NeedTnow** — Партнёрская программа: полная спецификация

---

## 1. Концепция

**Цель:** Привлечение новых исполнителей (провайдеров) и бизнесов через существующих пользователей.  
**Модель:** CPS (Cost Per Sale) — партнёр получает **20% от каждого платежа** привлечённого им пользователя  на протяжении **всего срока его активности** на платформе (Lifetime Revenue Share).

---

## 2. Механика (Step-by-Step)

### Шаг 1: Получение реферальной ссылки

- Любой зарегистрированный пользователь может стать партнёром.
- При регистрации автоматически генерируется уникальный `referral_code` (6-значный, буквенно-цифровой).
- Реферальная ссылка: `t.me/NeedTnow_bot?start=REF_CODE`

### Шаг 2: Привлечение реферала

- Новый пользователь открывает бота по реф-ссылке.
- Telegram Bot фиксирует `start` параметр.
- При регистрации в `profiles.referred_by` записывается `id` партнёра.

> ⚠️ **Атрибуция:** Первый клик — финальный (First-Click Attribution). Если пользователь перешёл по нескольким ссылкам, засчитывается первая.

### Шаг 3: Отслеживание платежей

- При каждой оплате подписки (PRO $19 или AI $49) срабатывает Supabase Edge Function `process-payment`.
- Автоматически создаётся запись в `partner_earnings`.
- Повторяющиеся платежи (продление подписки) **также** засчитываются партнёру.

### Шаг 4: Выплата

- Минимальный порог выплаты: **$20**
- Партнёр запрашивает выплату в `/partner` кабинете
- Доступные методы: TON кошелёк, USDT TRC-20, PromptPay (Таиланд), VietQR (Вьетнам)
- Срок обработки: **2–5 рабочих дней**

| Уровень | Требование | Бонус |
|---|---|---|
| 🥉 Starter | 1–4 активных реферала | 20% комиссия |
| 🥈 Silver | 5–19 активных рефералов | 22% комиссия |

## 5. Реф-ссылки и UTM параметры

Партнёр может создавать несколько реферальных ссылок с разными `utm_source` для отслеживания каналов:

```
t.me/NeedTnow_bot?start=REF123_instagram
t.me/NeedTnow_bot?start=REF123_vk
t.me/NeedTnow_bot?start=REF123_phuket_chat
```

В `profiles.referred_by` записывается базовый `referral_code` без суффикса (`REF123`).  
Полный тег хранится в `profiles.ref_source TEXT` для аналитики.

## 6. База данных (recap из 02_DATABASE_SCHEMA.md)

```sql
-- Запрос: баланс партнёра
SELECT 
  SUM(commission_amount) AS total_earned,
  COUNT(DISTINCT referred_user_id) AS total_referrals,
  COUNT(DISTINCT referred_user_id) FILTER (WHERE created_at > NOW() - INTERVAL '30 days') AS active_referrals
FROM partner_earnings
WHERE partner_id = 'your_user_id';

-- Запрос: история выплат
SELECT amount, status, payout_method, requested_at, paid_at
FROM partner_payouts
WHERE partner_id = 'your_user_id'
ORDER BY requested_at DESC;
```

## 7. Антифрод и защита

| Правило | Реализация |
|---|---|
| Нельзя быть рефералом самому себе | CHECK: `referred_by != id` |
| Атрибуция только при первой регистрации | `referred_by` не перезаписывается |
| Подозрительные аккаунты (0 активности) | Модерация при выплате > $100 |
| Чарджбэк / отмена платежа | Сторнирование начисления в `partner_earnings` |
| Выплата только на верифицированные кошельки | Верификация TON адреса через TON Connect |
