## ЧАСТЬ 1: ДИНАМИЧЕСКОЕ НИЖНЕЕ МЕНЮ (BottomNav)

---

### 1.1 Концепция: Контекстная навигация

Нижнее меню **динамически меняется** в зависимости от того, в каком разделе приложения находится пользователь. Это даёт:

- **Фокус** — пользователь видит только релевантные действия
- **Чистоту** — не перегружаем навигацию 7+ кнопками
- **Интуитивность** — при входе в Flash Market меню «подстраивается» под контекст барахолки

### 1.2 Два режима нижнего меню

```
РЕЖИМ 1: ОСНОВНОЙ (Услуги)
Когда пользователь на главном экране или в экранах аукциона услуг.

┌──────────────────────────────────────────────────────────┐
│  🏠         ⭐         ⚡        💬        👤          │
│ ГЛАВНАЯ   ОТКЛИКИ   СОЗДАТЬ    ЧАТ     КАБИНЕТ       │
│                     (FAB)                              │
└──────────────────────────────────────────────────────────┘

РЕЖИМ 2: FLASH MARKET (Барахолка)
Когда пользователь перешёл в раздел Flash Market.

┌──────────────────────────────────────────────────────────┐
│  🔥         🔍        📸        📦        👤          │
│ МАРКЕТ    ПОИСК   ПРОДАТЬ    МОЁ     КАБИНЕТ        │
│  (лента)          (FAB)    (архив)                    │
└──────────────────────────────────────────────────────────┘
```

### 1.3 Переключение между режимами

```
Вход в Flash Market:
  → Клик на виджет «🔥 FLASH MARKET» на главном экране
  → BottomNav плавно морфится в режим Market (250ms анимация)
  → Иконки fade-out → slide-up → новые иконки fade-in

Возврат в основной:
  → Кнопка «← Назад» на экране маркета
  → Или «🏠 ГЛАВНАЯ» в кабинете (если пользователь ушёл глубоко)
  → BottomNav возвращается в режим Услуг
```

### 1.4 Описание вкладок — Режим Flash Market

| # | ID | Иконка | Label | Описание |
|---|---|---|---|---|
| 1 | `market-feed` | 🔥 | МАРКЕТ | Лента всех активных лотов + фильтры + категории |
| 2 | `market-search` | 🔍 | ПОИСК | Полнотекстовый поиск по товарам + фильтры (цена, состояние, хаб, район) |
| 3 | `market-sell` | 📸 | ПРОДАТЬ | FAB-кнопка (выделенная) → открывает форму создания лота |
| 4 | `market-my` | 📦 | МОЁ | Объединённый архив: Мои лоты + Мои ставки + Мои покупки + Избранное |
| 5 | `account` | 👤 | КАБИНЕТ | Тот же профиль (универсальный для обоих режимов) |

| # | ID | Иконка | Label | Описание |

> Экран `📦 МОЁ` в нижнем меню маркета — **быстрый доступ** во время шопинга.

### 1.12 Анимация переключения контекста BottomNav

```css
/* Анимация морфинга между режимами */
.bottom-nav-transition {
  transition: all 250ms cubic-bezier(0.4, 0, 0.2, 1);
}

.nav-icon-enter {
  animation: slideUpFadeIn 200ms ease-out forwards;
}

.nav-icon-exit {
  animation: slideDownFadeOut 150ms ease-in forwards;
}

@keyframes slideUpFadeIn {
  from { transform: translateY(8px); opacity: 0; }
  to   { transform: translateY(0);   opacity: 1; }
}

@keyframes slideDownFadeOut {
  from { transform: translateY(0);   opacity: 1; }
  to   { transform: translateY(-8px); opacity: 0; }
}

/* Цветовая схема режимов */
.nav-services .nav-active { color: #00F2FE; }  /* Cyan — услуги */
.nav-market   .nav-active { color: #FF6B35; }  /* Orange-Fire — маркет */
```

### 2.9 Маршруты админ-панели

```
Новые маршруты (/admin/market/*):

  /admin/market                    — Дашборд Flash Market (статистика)
  /admin/market/listings           — Все лоты (таблица + фильтры)
  /admin/market/listings/:id       — Детали лота (полная карточка)
  /admin/market/auctions           — Аналитика аукционов (воронка, графики)
  /admin/market/deals              — Сделки маркета (таблица + статусы)
  /admin/market/deals/:id          — Детали сделки + чат
  /admin/market/appeals            — Апелляции по маркету
  /admin/market/moderation         — Модерация: новые лоты + репорты
  /admin/market/categories         — Управление категориями (CRUD)
```
