## 1. Название бренда

### Официальное написание
**`TuttoMinutto`** — одно слово, CamelCase с заглавными `T` и `M`.

> **Этимология:** *Tutto* (ит.) = всё · *Minutto* (ит.) = минута  
> **Смысл:** «Всё за одну минуту» — обратный аукцион, где исполнители откликаются мгновенно.

## 3. Дизайн-система

### 3.1 Цветовая палитра

```
Основные:
  bg-primary      #0D1117   ← фон приложения (почти чёрный)
  bg-card         #161B22   ← карточки и модалки
  bg-surface      #21262D   ← поля ввода, панели

Акцентные (бренд-цвета):
  cyan            #00F2FE   ← TUTTO, кнопки, активные элементы
  green           #00FF87   ← MINUTTO, успех, балансы
  gradient-brand  linear-gradient(135deg, #00F2FE 0%, #00FF87 100%)

Статусные:
  danger          #FF2A6D   ← ошибки, апелляции, удаление
  warning         #FFB302   ← предупреждения, таймеры, ожидание
  info            #58A6FF   ← информация, ссылки

Текст:
  text-primary    #FFFFFF
  text-secondary  #8B949E
  text-muted      #484F58
```

### 3.3 Логотип — правила использования

#### Вариант A: Горизонтальный (основной)
```
[⚡icon] TUTTO MINUTTO
              ↑cyan  ↑green
```
Используется: хедер приложения, баннеры, OG-изображения

#### Вариант B: Стек (вертикальный)
```
  TUTTO
MINUTTO
```
Используется: иконка приложения (1024×1024), splash-экран

#### Вариант C: CamelCase (текстовый)
```
TuttoMinutto
```
Используется: маркетинговые тексты, уведомления, системные сообщения

#### Цветовые варианты логотипа

| Фон | Вариант |
|---|---|
| Тёмный (основной) | **TUTTO** cyan + **MINUTTO** green |
| Белый (документы) | **TUTTO** #1A1A2E (тёмно-синий) + **MINUTTO** #00856F (тёмно-зелёный) |
| Монохромный | Оба слова белые с тонким разделителем или пробелом |

#### Охранная зона (логотип)
```
Минимальный отступ со всех сторон = высота буквы «T» в логотипе.
Никаких других элементов в охранной зоне.
```

#### Запрещённые практики
- ❌ Искажать пропорции логотипа
- ❌ Менять цвета на неутверждённые
- ❌ Добавлять тени или обводки
- ❌ Размещать на пёстром фоне без подложки
- ❌ Писать `TuttoMinutto` строчными буквами `tuttominutto` в тексте (кроме доменов)

## 4. Иконография

### Главная иконка приложения (App Icon)
```
Форма:   Squircle (Apple-стиль, радиус 22.5% от размера)
Фон:     Градиент #0D1117 → #161B22 (диагональ)
Символ:  Стрелки аукциона (↓↑) или молния + точка местоположения
Цвет символа: градиент cyan→green
```

### Иконки интерфейса
- Библиотека: **Lucide Icons** (consistent stroke-width 1.5)
- Размеры: 16px (inline), 20px (кнопки), 24px (nav), 32px (hero)
- Цвет: `text-secondary` по умолчанию, `accent-cyan` активное состояние

## 5. Голос бренда (Tone of Voice)

| Параметр | Описание |
|---|---|
| **Язык** | Русский (основной) + Английский |
| **Тон** | Дружелюбный, энергичный, конкретный |
| **Обращение** | На «ты» (в TMA), на «вы» (в юридических документах) |
| **Эмодзи** | Умеренно — в уведомлениях и UI; нет в юридических текстах |
| **Пунктуация** | Без лишних восклицательных знаков. Факты, а не крики. |

### Примеры фраз ✅ / ❌

| ❌ Не так | ✅ Правильно |
|---|---|
| Получи лучшее предложение ПРЯМО СЕЙЧАС!!! | Найди лучшее предложение за минуту |
| Ваша заявка успешно создана. Ожидайте. | Заявка опубликована — бизнесы уже видят её |
| NeedTnow приложение | TuttoMinutto |
| Деньги пришли на ваш счёт! | 💰 +500 токенов зачислены |

## 10. Слоган (официальный)

### ✅ Утверждён

> # «Здесь выбираешь ты!»

**EN версия:** *Here, you choose!*

---

### Почему это работает

| Элемент | Роль |
|---|---|
| **«Здесь»** | Неявное противопоставление Telegram-каналам: *не там — а именно здесь* |
| **«выбираешь ты»** | Инверсия усиливает «ты» — пользователь в центре и контроле |
| **«!»** | Энергия и уверенность без крики |

Слоган отвечает на главный страх пользователя Telegram-каналов:  
*«Я не понимаю, кто эти люди, цены непонятные, нет гарантий»*  
→ «Здесь выбираешь **ты** — с рейтингами, проверенными бизнесами и защитой платформы»

---

### Применение

| Контекст | Вариант |
|---|---|
| Под логотипом (основной) | `Здесь выбираешь ты!` |
| Лендинг / OG-description | `TuttoMinutto — здесь выбираешь ты!` |
| BotFather `about` | `Здесь выбираешь ты — сервисы на курорте за 1 минуту` |
| Сторы (subtitle) | `Здесь выбираешь ты!` |
| Push-уведомления (intro) | не используется (слишком длинно для push) |
| Английская аудитория | `Here, you choose!` |
| Хэштег | `#TuttoMinutto #здесьвыбираешьты` |
