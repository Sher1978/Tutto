## Навигационная карта (B2B Sitemap)

```
/feed                ← общая лента заказов (Tab 1) — такая же как у клиента
/bids                ← мои активные отклики (Tab 2)
/chats               ← активные сделки (Tab 3)
/b2b                 ← B2B кабинет (Tab 4)

/b2b/dashboard       ← главная B2B
/b2b/profile         ← редактирование бизнес-карточки
/b2b/ai-agent        ← настройка AI Sales Agent
/b2b/wallet          ← токен-кошелёк
/b2b/subscription    ← Premium (Verified Partner)
/b2b/analytics       ← статистика
/b2b/reviews         ← управление отзывами

/payment             ← покупка токенов (общий)
/b2b/onboarding      ← первоначальный AI-опрос
```
