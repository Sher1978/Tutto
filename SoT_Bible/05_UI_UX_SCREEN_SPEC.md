### Screen 3: Создание заказа (`/create`)

**Stepper (шаги 1-4):**
- Шаг 1: Выбор категории L1 (Grid 2 колонки, иконки + названия)
- Шаг 2: Уточнение L2 → L3 (Chips + список с ценовыми подсказками)
- Шаг 3: Форма заполнения
  - Input: Заголовок (auto-prefilled из L3)
  - Textarea: Описание + 🎤 voice input
  - Photo Upload: drag-drop / camera (до 3 фото)
  - Select: Район (по хабу)
  - Budget: input field ($) + toggle «Жду предложений»
- Шаг 4: Превью + Кнопка «Опубликовать»

## 4. Анимации и микро-взаимодействия

| Элемент | Анимация |
|---|---|
| Карточки в ленте | fade-in + slide-up при загрузке (staggered, 50ms delay) |
| Новый оффер (Realtime) | карточка появляется сверху списка с bounce-эффектом + зелёная вспышка |
| FAB кнопка | scale 1.0 → 1.05 при hover, glow pulse при idle |
| Toggle AI | Spring animation с glow при включении |
| Stepper (создание заказа) | slide left/right между шагами |
| Pull-to-refresh | Custom neon spinner в стиле бренда |
| Принятие оффера | Confetti + зелёная волна (success animation) |
